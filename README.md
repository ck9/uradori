# Uradori

SNS上の投稿に「AIでファクトチェック」ボタンを追加し、OpenAI APIのWeb検索で**投稿を要素ごとに**裏取りし、判定を色分けで表示するChrome拡張機能です。

## インストール方法

1. GitHubで「<>Code」→「Download ZIP」を押してZIPをダウンロードし、展開する
2. Chromeで `chrome://extensions` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」→ ZIP展開後のフォルダを選ぶ
5. ツールバーの拡張機能アイコン（虫めがね）をクリック → OpenAI APIキーを入力して「設定を保存」
6. 対象のページをリロードする

## 使い方

- 投稿のアクションバー(返信・リポスト…)のすぐ上に出る青い「AIでファクトチェック」ボタンを押すと、すぐに検証が始まります
- 結果パネルの構成
  - **結論（タップで根拠を表示）** … 「1分でわかる結論」のカード
  - **投稿の要素ごとの判定（タップで根拠を表示）** … 直下に判定の内訳（色の凡例も兼ねる）、
    その下に主張ごとの色付きカード
  - カードを開くと **説明 → この情報だけでは判断できないこと（箇条書き）→ 根拠n件** の順に表示
  - 根拠はURLの生表示ではなく**ページタイトルのリンク**で、右端の ↗ で外部リンクと分かるようにしています
- 検証が済んだ投稿のボタンは、判定の色で「結果を見る（判定）」に変わります。

### 判定の色

| 判定 | 色 |
| --- | --- |
| 正確 | 緑 |
| 誤解を招く | 橙 |
| 誤り | 赤 |
| 裏取り不能 | グレー |
| 検証対象外（意見・予測など） | 薄いグレー |

## 設定

拡張機能アイコンをクリックすると出る小さな設定画面で指定します。
画面はブラウザがダークテーマでも常にライト表示です。

- **APIキー** … `chrome.storage.local` にのみ保存。送信先は `api.openai.com` のみ
- **モデル** … GPT-5.6 Luna（低コスト・既定）/ GPT-5.6 Sol（高精度）/ GPT-6 Astra（最高性能）
  実際に送るモデルIDは `gpt-5.6-luna` / `gpt-5.6-sol` / `gpt-6-astra` です

## 対応サイト

現在は `x.com` / `twitter.com` の投稿に対応しています。
別のサイトを足すときは、`manifest.json` の `content_scripts.matches` と、`content.js` の
投稿の抽出（`extractTweet`）・ボタンの挿入位置（`injectButton` / `mountRow`）を追加します。
判定ロジックとパネルはサイトに依存しないので、そのまま使えます。

## 仕様上の注意

- AIによる自動判定です。重要な判断の前に必ず根拠リンクを開いて確認してください。
- Webサーチを伴うため1回あたり30秒程度、数円〜数十円のAPI利用料がかかります。
