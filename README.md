# Uradori

SNS上の投稿を、AIがWeb検索で裏取りするChrome拡張機能です。

投稿の下に出る「AIでファクトチェック」ボタンを押すだけで、投稿の中身を一つひとつの主張に分け、それぞれが正しいかどうかを根拠リンクつきで色分けして表示します。

## はじめる前に

利用にはOpenAIのAPIキーが必要です。

- [OpenAIのAPIキー管理ページ](https://platform.openai.com/api-keys) でキーを作成してください（`sk-` で始まる文字列です）
- APIの利用は有料です。事前にOpenAI側で支払い方法の登録が必要です

## インストール

1. このページ上部の緑の「Code」ボタン →「Download ZIP」でダウンロードし、ZIPを展開します
2. Chromeのアドレスバーに `chrome://extensions` と入力して開きます
3. 右上の「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」を押し、展開したフォルダを選びます

## 初期設定

1. ツールバーのUradoriのアイコン（青い虫めがね）をクリックします
2. 「OpenAI APIキー」欄にキーを貼り付けます
3. 「使用モデル」を選びます（迷ったらそのままでOKです）
4. 「設定を保存」を押します
5. 開いているXのページを再読み込みします

### 使用モデルの選び方

| モデル | 特徴 |
| --- | --- |
| GPT-6 Luna | 低コスト。はじめはこちらがおすすめです（既定） |
| GPT-6 Sol | より丁寧に確認します |
| GPT-6 Astra | 最も高性能。料金も高めです |

## 使い方

1. Xで気になる投稿を見つけたら、返信・リポストなどのボタンのすぐ上にある青い「**AIでファクトチェック**」ボタンを押します
2. 確認中はボタンに経過時間が表示されます。30秒ほど待つと、投稿の下に結果が表示されます
3. 結果を読み終えたら「閉じる」で閉じられます。ボタンは判定の色に変わり、「**結果を見る（判定）**」から何度でも見返せます

投稿に画像が付いている場合は、画像の内容も確認の対象になります。

### 結果の見かた

結果は上から次の順に並んでいます。

- **1分でわかる結論** … 投稿全体についてのひとことまとめです
- **投稿の要素ごとの判定** … 投稿に含まれる主張ごとの判定です。いちばん上に判定の内訳が並び、その下に主張ごとのカードが続きます

結論や各カードはタップすると開き、次の内容が表示されます。

- **説明** … その判定になった理由
- **この情報だけでは判断できないこと** … 裏取りしきれなかった点
- **根拠** … 判定の参考にしたWebページです。タップすると新しいタブで開きます

結果の下にある「**再検証**」を押すと、もう一度確認し直します。

### 判定の色

| 判定 | 色 | 意味 |
| --- | --- | --- |
| 正確 | 緑 | 根拠によって裏付けられた |
| 誤解を招く | 橙 | 一部は正しいが、誤った印象を与えるおそれがある |
| 誤り | 赤 | 根拠と食い違っている |
| 裏取り不能 | グレー | 確かめられる情報が見つからなかった |
| 検証対象外 | 薄いグレー | 意見や予測など、正誤を判定できない内容 |

## ご注意

- **ファクトチェック結果はAIによる自動生成です。** 間違えることもあります。重要な判断をする前に、必ず根拠リンクを開いてご自身で確認してください
- **1回の確認ごとにOpenAIのAPI利用料がかかります。** 目安は数円〜数十円で、上位のモデルほど高くなります
- APIキーはお使いのブラウザ内にだけ保存され、OpenAIへの問い合わせ以外には使われません
- 現在対応しているのは X（`x.com` / `twitter.com`）のみです

## 困ったときは

- **ボタンが表示されない** … Xのページを再読み込みしてください。拡張機能を更新・再読み込みした直後は、ページの再読み込みが必要です
- **「はじめに設定が必要です」と出る** … APIキーが未登録です。「初期設定」の手順でキーを保存してください
- **「確認できませんでした」と出る** … APIキーが正しいか、OpenAI側の残高や支払い設定に問題がないかを確認してください

## 開発者向け

別のサイトに対応させる場合は、`manifest.json` の `content_scripts.matches` と、`content.js` の投稿の抽出（`extractTweet`）・ボタンの挿入位置（`injectButton` / `mountRow`）を追加します。判定ロジックと結果パネルはサイトに依存しないため、そのまま使えます。

APIキーは `chrome.storage.local` に保存され、送信先は `api.openai.com` のみです。
